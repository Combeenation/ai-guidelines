# AI Guidelines

This repository is the central source of truth for **Combeenation's AI-assisted development guidelines**.

It defines shared coding standards, best practices, and quality expectations for AI coding assistants such as Codex, Claude Code, and GitHub Copilot. The goal is to keep AI-generated and AI-modified code consistent, maintainable, and aligned with our engineering standards across teams and customer projects.

By maintaining these guidelines in one place, we can evolve our standards without duplicating them across projects or tools.
